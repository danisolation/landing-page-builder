- Never commit or push to git unless explicitly asked; act only on the specific occasion requested ("bạn không được tự ý push nhé"). Confidence: 0.95
- Keep changes strictly within the requested scope — when asked for a narrow task like adding i18n, do not also change UI/layout; user was frustrated by unrelated UI changes ("thêm i18n thôi mà chứ có đổi UI đâu", "đừng thay đổi UI của app nha"). Confidence: 0.9

After implementing, also run the full verification suite — typecheck, unit tests, FE + BE builds, curl against new API endpoints — and a live browser smoke test of the real user flows (login, desktop + 375px screenshots), fixing whatever the smoke test surfaces (missing translations, new lint errors) in the same pass. Confidence: 0.9
- Prefer mature libraries over hand-rolled implementations (e.g., a toast library everywhere, not alert()); from now on use the newest possible library/technology versions. Confidence: 0.85
- When (re)designing UI, research and reference beautiful modern sites (top landing pages, e.g. Linear/Vercel-class) rather than inventing styles from scratch — user explicitly asks to "research how others do it" before implementing. Confidence: 0.8
- Git author identity should be the personal account: danisolation <tranquocdungb4@gmail.com> — not a company account and not tool names like "claude". Confidence: 0.75
- Gives very brief, direct commands ("push đi", "continue", "fix all priorities") — expects the agent to understand intent without lengthy explanations or confirmations. Confidence: 0.8

- Windows cmd gotchas: unix filters (`tail`) don't exist in pipes, `cat` doesn't exist either (use `type`), and `cd` inside a compound command breaks the chain — pass the cwd parameter to the shell tool instead of chaining `cd`; the file-read tool treats bracketed path segments as glob patterns, so Next.js dynamic-route files like `src/app/[locale]/(admin)/pages/[id]/edit/page.tsx` can't be read directly — read them via `git diff/show -- <path>` or shell `type` instead; also check tool availability up front (ffmpeg subtitles filter, installed Playwright browsers) before committing to a capture approach; output deliverables the user may have open in a player (rendered mp4s) get locked by Windows — when ffmpeg/render hits Permission denied on the final artifact, render to a temp filename and swap (Remove-Item + Rename-Item, with a still-locked fallback report) instead of retrying in place. Confidence: 0.8

Confidence: 0.85
